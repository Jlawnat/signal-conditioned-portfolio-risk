# Statistical validity and confirmation plan

The A/B/C daily NAV series are paired by the same 282 dates, but policy decisions change future positions. A daily paired difference is an observed **policy-path difference** under a shared market history, not an independent randomized treatment effect. Daily returns, overlapping 20-session entry forward returns, volatility windows and position lifecycles are serially dependent. The sample is one contiguous market period that was inspected before this post-hoc outcome hierarchy was written. It has no untouched holdout and uses retrospectively current index constituents.

**Supported now:** numerical descriptions of each stored simulated path; paired date plots; own-budget and common-4% observed exceedance counts; deployment, fills, modeled costs and NAV. The existing A-entry month-cluster bootstrap interval for 20-session stock-minus-SPY forward returns is [−2.1835, 0.4138] percentage points. It crosses zero, samples selected executed entries and only partially represents temporal dependence. It does not establish signal quality, overlay superiority or a general population effect.

**Unsupported now:** independent replication from 282 daily rows, a causal policy effect beyond the fixed simulation comparison, statistical significance, future profitability, unbiased historical S&P 500 performance or a claim that policy C “wins” because of fewer own-budget exceedances. No new p-value is computed for V2.

**Feasible exploratory work:** paired daily return differences with date-block resampling or HAC sensitivity after declaring block length and estimand; event-level breach-duration summaries; sensitivity to costs and verified corporate actions. Such intervals would remain exploratory on the inspected path and would not repair survivorship bias or model-fidelity uncertainty. Avoid mechanically treating overlapping trade outcomes as independent.

**Future confirmation protocol:** freeze exact candidate, order, fill and corporate-action code and hashes; reconstruct point-in-time constituents; prespecify primary exposure and budget-compliance estimands, common-4% contrast, and secondary NAV/deployment outcomes; declare a new genuinely future period before observing it; keep A/B/C and V4/V5-U definitions fixed; audit all fills and actions; use paired date blocks or a justified dependence model for uncertainty. Record all deviations. Stronger external conclusions require an independently reproducible pipeline, verified actions, a credible future or untouched period and uncertainty intervals aligned with dependence. The current manuscript remains an exploratory case study.
