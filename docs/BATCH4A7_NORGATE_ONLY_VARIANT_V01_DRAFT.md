## Design and meaning

In a future isolated adapter/runner apply identical changes to A, B and C: remove the 24% sector exposure cap and remove the Unknown-sector entry rejection. Neither historical sector labels nor current labels enter signal generation, rank, position sizing, order acceptance or exit decisions. Sector-based results cannot be claimed PIT; optional current-label descriptive summaries must be explicitly dated and cannot be causal or constraint compliance evidence.

Keep the original signal structure and 270-bar warmup as the reference, with a separately versioned input transformation: at each T physically truncate stock and SPY at T; require 270 matching valid bars, at least 126 actual prior observations, and an observed T bar. Normalize TOTALRETURN historical OHLC to raw T price units with raw_close(T)/TR_close(T); normalize capital-adjusted volume with the independently checked same-T capital-volume convention. Use NONE raw T close for absolute minimum-price constraints and raw unadjusted turnover/price-volume for the economic liquidity constraint. Compute indicator ratios, trend, pullback, score and stops from the normalized signal history; convert stops to raw T units consistently. This departs from the original frozen feature inputs and requires synthetic factor-invariance/quantity/stop tests and a code specification before freeze. It is **not implemented or certified by the 4A.7 feature reachability screen**, which uses the original frozen pure function with TOTALRETURN input. Recompute terminal reachability under the final normalized design before approving exclusions.

No member is removed solely for insufficient history. There is no invented signal until readiness. No raw executable price is padded. Handle distributions and splits with the verified raw-share cash/receivable/action ledger described in BATCH4A7_DATA_CLEARANCE.md; unresolved reachable terminal consideration or held actions fail closed. A historical-vintage guarantee cannot be asserted from a current extract; state corrected-history/current-acquisition limits. Revisions require an incremented version and change rationale.

Define empty initial holdings and the same initial cash, order timing and costs for every policy before any portfolio run. B-A mean positive exceedance above the common 4% marked stop-gap reference is the primary historical contrast. C is secondary; choose its fixed-budget mechanism comparator from pre-study calibration, not comparison-period results. Retain the common 4% and own-policy thresholds separately. Choose the time-block uncertainty procedure, block length rule, confidence level, multiplicity, missing-date/exclusion handling and mechanism estimands prospectively; this draft deliberately does not invent approved values. S2 denominator convention and executor/action adaptation require review. New outputs must have an independent private versioned namespace and complete S0-S5 provenance.

Permitted future claims, conditional on gate passage and actual results: within this named sector-free, Norgate-defined constituent historical model, estimate policy differences in marked stop-gap exposure, decision/open implementation gap, turnover, capital deployment and realized simulated outcomes under stated costs/action assumptions. Neither investment advantage, novelty nor statistical significance is assumed. Cannot claim original-strategy exact replication, historical sector-cap compliance, independent out-of-sample confirmation, live execution quality, VaR/ES/loss guarantees or a cleared dividend/terminal ledger before evidence exists.

Freeze requires the full 4A.7 matrix, concrete signal adapter/accounting tests, documented membership/class scope, no material unresolved reachable actions/settlements, final statistical definitions and dated researcher review. Approval to draft this variant is not approval to run 4B. No manuscript or existing protocol was edited.

## Trial-feasible window amendment within draft v0.1

The full 282-session original window is not feasible with the verified 270-bar startup requirement in this trial: SPY has only 217 preceding bars at its first session. The proposed **NG-SF-270-LW v0.1** alternative starts an empty portfolio on the first common study date with 270 actual valid SPY bars including that date, then permits T-close decisions and following-open fills. Stock-specific 270 aligned-bar qualification still applies independently. This is an availability-driven start rule selected before any portfolio results, not a shorter warmup chosen to recover performance. Record the computed exact boundary, active observation count, first decision/fill, final pending-order treatment and input hashes before freeze. Exclude earlier days from estimands; never dilute exceedance statistics with forced no-signal zero-exposure dates. All A/B/C/comparator policies share this later window and start state.

The draft sector-free transformation and late-window change jointly define a different experiment. It cannot estimate the original full 282-day policy comparison or reproduce its sector constraint. It remains exploratory because these dates have already been examined. Retain the original full-window design as BLOCKED, do not silently replace its calendar, and obtain dated approval of this named later-window variant before 4B. Signal/history normalization, corporate actions, terminal cases and statistics still need clearance. No purchase, API key, WRDS access or request for trial extension is a dependency of this proposal.
