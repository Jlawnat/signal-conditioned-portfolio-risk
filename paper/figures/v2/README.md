# V2 figure provenance

`fig01_timing.svg` is generated by `python3 scripts/paper/generate_v2.py` from `paper/tables/v2/risk_timing_sample.json`. That JSON is generated by `python3 scripts/paper/batch3_risk_timing.py` from immutable V5-U daily/fill outputs, local raw/adjusted price panels and the candidate CSV. The four plotted stages are T close before planning, a *hypothetical* T-price state after the following session's executed sell quantities, T+1 open after actual simulated fills, and T+1 close. Dashed lines show each policy's T-date own budget. The figure is a selected-case diagnostic, not the 282-session breach distribution.

V2 reuses the ten numerically reconciled V1 figures in `paper/figures/` for NAV, drawdown, stop-gap risk, own and common budgets, invested/cash shares, exceedance counts, fills, costs and budget schedule. `python3 scripts/paper/generate.py` documents and checks their source mapping. V4 and V5-U are kept separate in `paper/tables/table04_regimes.md`. No cash-interest shadow is plotted as portfolio NAV.
